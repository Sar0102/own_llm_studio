# Document Validator — Required Sections (общий перечень)

Канонический перечень обязательных секций и **файлов** по типам документов. Источник — стандарт
«3.3.2. Контент документов на программный продукт» (требования `DOC-*`). Согласован с графом
(`Source Graph` в orchestrator SKILL).

**Расположение:** `document-validator/required-sections.md`. Путь: из **orchestrator**
(`document-validator/SKILL.md`) — `./required-sections.md`; из **worker**
(`document-validator/worker/SKILL.md`) — `../required-sections.md`.

## Модель проверки (важно)

- **Одна секция = один файл.** Тип документа — это **папка**; каждая секция лежит в своём `.md`.
  Поэтому «раздел отсутствует» = **файл секции отсутствует в папке типа**.
- Один воркер обрабатывает **один файл**, поэтому:
  - **worker** проверяет *содержимое* своего файла (заголовки, требуемые разделы 2–3 уровня,
    таблицы/UML, `include`, ссылки) и кладёт в факт `covered_sections` то, что покрыл;
  - **orchestrator** проверяет *полноту набора файлов* в папке типа — сверяет фактический список
    файлов с перечнем ниже и выдаёт `CVAL-SEC` за отсутствующие секции-файлы.
  - Воркер **не** выдаёт «секция отсутствует» — он не видит соседние файлы.
- **Уровень требования → severity:** `ДОЛЖЕН` → **ERROR**; `СЛЕДУЕТ` → **WARNING**;
  `РЕКОМЕНДАЦИЯ`/`РЕКОМЕНДУЕТСЯ`/«допускается» → **INFO/SUGGESTION** (никогда не ERROR).
- **Условные документы/секции** («при наличии …») — отсутствие не ошибка, если условие не выполнено.
- **Автогенерируемые** секции (АС Документация Сотрудники) не флагать как отсутствующие по контенту.
- В `advice`/`message` указывай ID требования (`DOC-AB-06` и т.п.) — это делает находку проверяемой.
- **Параметризованные имена** (`{постфикс}`, `{use_case_name}`, `{dd_name}`, `{pattern_name}`,
  `{номер_версии}`) — это шаблоны: сопоставляй по маске, не требуй буквального имени.

## Неизвестный тип

Если папка/файл не соответствует ни одному типу из перечня — `CVAL-SEC` не выдавать; поставить один
`INFO`, что для типа нет определённых обязательных секций в спецификации.
